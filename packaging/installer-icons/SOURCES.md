# Installer icon sources

The `rail-*`, `menu.svg`, `edit.svg`, and `arrow-*.svg` assets are unmodified
symbolic SVG icons copied from Ubuntu's installed `yaru-theme-icon` package
(`/usr/share/icons/Yaru/scalable`). The upstream theme is at
https://github.com/ubuntu/yaru. The package copyright metadata is preserved in
[COPYRIGHT-Yaru.txt](COPYRIGHT-Yaru.txt), including the licenses for its
different artwork. Application-specific icons already present in this
directory retain their existing sources and are not changed by this display
update.
