**Requirement determined:** `self_installer.build_and_write_self_installer`
  gains `admin_password: str | None` - when given, it becomes the real
  Proxmox root password (never echoed back, since it's already known);
  `drive_admin.build_self_installer` forwards `runner.password` (the
  real submitted `SudoRunner` password) automatically, no new field
  needed anywhere in the web UI.
**Two more real bugs found while wiring this in, both fixed in the
  same pass:**
  1. `hash_password_sha512crypt` requires real `bytes`
     (`b"\n" in password`) - a bare `pw = admin_password` passed a
     `str` straight through and crashed with `TypeError` the instant
     this branch was actually exercised. Fixed: `.encode("utf-8")`.
  2. The *prior* one-time-password fix had its own bug: `generate_one_
     time_password()` returns `bytes`, and embedding it directly in an
     f-string rendered Python's own `b'...'` repr (quotes and the `b`
     prefix) as if that were part of the real password - typing the
     displayed text verbatim would never have worked. Fixed:
     `.decode("ascii")` before display, kept separate from the raw
     bytes actually used for hashing.
**Files changed:** `self_installer.py` (`admin_password` parameter,
  bytes/display fixes), `drive_admin.py` (forwards `runner.password`).
**Verification:** Full suite 1514/1514 (was 1511). New tests: proves
  `drive_admin.build_self_installer` forwards the exact submitted
