# V0.2 remaining-work queue

Status: **living document - edit in place, not append-only** (matching
`v0.1-work-queue.md`'s own convention). Source of truth for "what's
done and what's left under V0.2, in what order." Started 2026-09-28,
backfilled with everything decision records 83-93 already built (none
of it was ever tracked in `v0.1-work-queue.md`, which stops at record
82) plus new candidate items raised since.

## How to use this

Same discipline as `v0.1-work-queue.md`: take the first `[ ]` item
whose **Blocked on** column is empty, TDD it, decision-record it if
it's a real design decision, mark it `[x]` with the commit hash(es)
and decision-record number in **Closed by**, update
`SESSION_HANDOFF.md`'s narrative to match. A `[~]` item is real but
partial - say exactly what's still missing in **Closed by**, don't
silently call it done.
