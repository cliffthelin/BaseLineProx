## How to use this

1. Take the first `[ ]` item whose **Blocked on** column is empty.
2. Work it: TDD as usual, decision record if it's a real design
   decision, changelog entry, commit implementation then docs
   separately (this project's standing convention).
3. Mark it `[x]`, add the commit hash(es) and decision-record number in
   the **Closed by** column, and update `SESSION_HANDOFF.md`'s audit
   section to match (that doc is the narrative; this one is the queue).
4. If working an item reveals a new one, add it to the bottom with the
   same columns, don't silently fold it into an existing row.
5. An item with something in **Blocked on** is not next - skip to the
   next unblocked `[ ]` row instead of stalling the whole queue on it.
