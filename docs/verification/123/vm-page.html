ChromeOSGoogle ChromeOS is hardware-specific. ChromeOS Flex is a different product; no ChromeOS guest recipe implemented.
GrapheneOSSupported-device releases or a source-built development emulator; not an LXC template. Emulator build/run integration remains open.

For an ISO: download and verify the vendor image into the selected installer cache, create an ISO VM below, install using its console, shut down, eject the ISO, and freeze the clean installation as a base. New overlays get a separate blank retained disk; it is not automatically mounted by these distros. Configure and verify its filesystem and mount before trusting an OS reset. Ubuntu is the automated retained-home recipe.
